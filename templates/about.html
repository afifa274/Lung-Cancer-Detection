About Lung Cancer Detection

A free, open-source lung cancer risk estimation tool powered by deep learning.

The model

Lung Cancer Detection uses a multi-layer neural network trained on a publicly available lung cancer patient dataset. The network takes 23 clinical and lifestyle factors as input and outputs the probability of belonging to one of three risk classes: Low, Medium, or High.

  • Architecture: Dense(128) → BN → Dropout(0.3) → Dense(64) → BN → Dropout(0.2) → Dense(32) → Softmax(3)
  • Loss function: Categorical cross-entropy
  • Optimiser: Adam (lr = 0.001) with ReduceLROnPlateau
  • Training: Up to 150 epochs with early stopping (patience = 15)
  • Preprocessing: StandardScaler (zero mean, unit variance)
  • Split: 80 % train / 20 % test, stratified by class

The factors assessed

Each of the 23 inputs is scored on a 1–9 scale by the user:

  • Age
  • Gender
  • Air pollution exposure
  • Alcohol use
  • Dust allergy
  • Occupational hazards
  • Genetic / family risk
  • Chronic lung disease
  • Balanced diet
  • Obesity
  • Smoking
  • Passive smoke exposure
  • Chest pain
  • Coughing blood
  • Fatigue
  • Unintentional weight loss
  • Shortness of breath
  • Wheezing
  • Swallowing difficulty
  • Clubbing of fingernails
  • Frequent colds
  • Persistent dry cough
  • Snoring intensity

REST API

Lung Cancer Detection exposes a /api/predict endpoint for programmatic access. Send a POST request with a JSON body containing all 23 fields: 

POST /api/predict
Content-Type: application/json

{
  "age": 45,
  "gender": "male",
  "air_pollution": 3,
  "smoking": 7,
  ...
}

→ 200 OK
{
  "outcome": "High",
  "percent_low": 5.2,
  "percent_medium": 18.1,
  "percent_high": 76.7,
  "advice": ["Heavy smoking is one of the strongest risk factors..."]
}

The dataset originates from publicly available lung cancer research data. The model has not been validated in a clinical setting.
